# Work folders

One folder per ask: `work/YYYY-MM-DD-short-slug/`. Typical contents, in order:

| File | Made by | Purpose |
|---|---|---|
| `ask.md` | PM | The ask verbatim, who asked, when, any thread or context |
| `intake.md` | `intake` | Interpretations, assumptions, questions, search terms |
| `landscape.md` | `landscape-map` | What exists, what's in flight, who owns what, gaps |
| `coverage.md` | `coverage-review` | Lens-by-lens coverage, unknowns, questions, risks |
| `questions.md` | `intake` / `coverage-review` | Questions by person, with answers as they come in |
| `prd.md` | `prd` | The draft PRD, every claim traceable |
| `review-N.md` | `critical-review` | Simulated senior review of a draft |
| `feedback.md` | PM | Real reviewer feedback, later logged by `review-feedback` |

Other asks (RFP, gap analysis, call prep, marketing review) use the same folder pattern.
