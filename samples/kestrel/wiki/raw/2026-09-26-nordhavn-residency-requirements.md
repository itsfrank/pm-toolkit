# Nordhavn Logistics: EU data residency requirements for analytics vendors

Sent by Nordhavn procurement on 2026-09-26 after the 2026-09-24 call. Version 1.0.

| Ref | Requirement |
|---|---|
| NR-1 | All customer event data is stored in the EU. |
| NR-2 | Event data is received and processed in the EU, including any queue or buffer. |
| NR-3 | Backups and disaster-recovery copies stay in the EU. |
| NR-4 | Dashboard query results and caches stay in the EU. |
| NR-5 | Vendor support access to our data requires our approval and is logged. |
| NR-6 | Vendor support tools do not copy our data outside the EU. |
| NR-7 | We can restrict our own users' access to data by their location. |
| NR-8 | Scheduled exports can be delivered to our own EU storage bucket. |
| NR-9 | The vendor publishes a subprocessor list with locations. |
| NR-10 | Existing data can be moved to the EU region without data loss. |
