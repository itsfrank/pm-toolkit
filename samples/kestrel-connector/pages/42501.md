# Security overview: encryption

Internal reference. Not reviewed for customer-facing use; request approved wording from
Security Engineering before quoting.

- At rest: Warehouse data, snapshots and the spool are encrypted with AES-256 using AWS KMS
  keys held in the same region as the data.
- In transit: all public endpoints (ingest, app, API) accept TLS 1.2 or 1.3 only. TLS 1.0
  and 1.1 were switched off on 2025-02-01.
- Internal service-to-service traffic uses mutual TLS.
- Key rotation: yearly, automatic.
