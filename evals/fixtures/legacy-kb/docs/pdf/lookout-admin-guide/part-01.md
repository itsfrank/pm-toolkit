# Lookout administration guide v2 (part 1 of 2: pages 1-22)

## 1. Roles and access grants (p. 1-14)
Lookout has three roles: Viewer, Agent and Supervisor. Supervisors grant tenant access for a
maximum of 72 hours per grant. Enterprise tenants must approve access in their settings.

## 2. Audit trail of support access (p. 15-22)
Every Lookout session is logged with the agent, tenant, start and end time. The audit trail
is kept for 400 days and is visible to the tenant's admins in Kestrel Govern.
