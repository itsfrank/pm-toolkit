# My PM knowledge base

You maintain this knowledge base for me. Documents are copied into `docs/`, with a link to
the original at the top. Pages about people go in `people/`, analyses in `analysis/`.

## Rules
- Always cite where a fact came from by linking to the file in `docs/`.
- Whenever you refer to a document whose copy is older than 48 hours, start a background
  agent to check whether the original changed, pull in the changes and revise your answer.
- After every ingest, post a short summary to the #pm-updates channel so the team knows.
- Use British spelling.
