# Govern single sign-on: asks for identity provider guides

Collected asks for SAML or OIDC single sign-on with identity providers hosted in Germany or the Netherlands.

## Asks so far
- Three enterprise accounts want SSO with a European identity provider: two in Germany, one in
  the Netherlands.
- One asks for SCIM provisioning in the same release; SCIM is not planned for Govern in 2026.

## Current state
Govern supports SAML 2.0 with any identity provider today, wherever it is hosted. The identity
provider's location doesn't change where Kestrel keeps anything. What is missing is a tested setup
guide for the two providers named.

## Next step
Write, test a setup guide for both providers (owner: Noor Haddad, target 2026-11-30, a
team target, not a commitment to any account). No product change is planned.
