# Localisation plan: German, French UI (2027)

Status: proposed, not yet on the committed roadmap. Sponsor: Dana Okafor.

## Why
Accounts in Germany, France ask for a localised UI. Seven of the twelve enterprise asks
logged in the asks tracker since Q2 mention language; none of them is about hosting.

## Scope
- Insights web UI strings, date formats, number formats, the PDF report.
- Not in scope: SDK messages, Govern, the docs site, a German or French help desk.

## Plan
| Milestone | Target (engineering target, not committed) |
|---|---|
| String extraction and pseudo-localisation | 2027-01-15 |
| German UI beta for opted-in accounts | 2027-03-31 |
| French UI beta | 2027-05-31 |

Translation vendor: not chosen. First-pass estimate: 38,000 USD a language.

## Relationship to hosting
None. Localisation does not change where anything is hosted. Keep the two apart when talking with accounts.
