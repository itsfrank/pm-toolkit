# Tern Replay product overview

Tern Replay records user sessions (DOM snapshots and events) in web and mobile apps so
product teams can watch how people use a feature.

- About 140 customer workspaces, mostly mid-market SaaS.
- Recording SDKs for web (JavaScript) and iOS; Android is in beta.
- Privacy masking of text inputs is on by default; see [PRD: Replay privacy masking](7112-prd-replay-privacy-masking.md).
- Recordings are stored in AWS us-west-2. There is no EU storage option today.
- Owner: Replay team (PM Ola Brandt).
