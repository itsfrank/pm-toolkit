# Kestrel integration plan

Status: draft, owned by Ola Brandt. Not approved.

1. Q4 2026: single sign-on with Kestrel accounts.
2. Q1 2027: Tern Replay events flow into Kestrel Collect through Collect's EU endpoint, so
   EU customers get EU processing end to end.
3. Q2 2027: Replay sessions linked from Kestrel Insights dashboards.
4. EU storage for Replay is deferred until Kestrel's Warehouse EU region (Fjord) is GA.
